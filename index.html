06

Failure Taxonomy

Failure types considered by the evaluation environment.

01

No Traction

The agent makes tool calls without meaningful progress toward the target state.

02

Irrecoverable Drift

The execution moves away from the valid route and cannot recover without restarting or backtracking.

03

Weak Recovery

The agent detects a problem but does not efficiently recover using an alternative path.

04

Format Error

A tool produces an output that does not match the expected result format.
